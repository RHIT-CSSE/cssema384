Lab 02: Data Acquisition and Cleaning

Graded: 20 points. Individual notebook submission.

Learning objectives

  • Acquire data and distinguish identifiers, categorical features, and numerical measurements.
  • Detect and address data quality problems with justified cleaning choices.
  • Apply min-max normalization to appropriate measurements and validate results.

Preparation

Complete Lab 01. Read DSD 1.1–1.3, 3.1.1–3.1.2, 3.2, 3.3.1–3.3.3, and 4.3. Review data types, acquisition, errors, missing values, and normalization.

Graded checkpoints

  1. Acquire and inspect (3 points): load the CSV, identify features and types, and summarize the data.
  2. Identify quality issues (4 points): find missing values, duplicates, inconsistent categories, and unexpected values.
  3. Clean data (5 points): address quality problems and explain your choices; preserve the raw data.
  4. Normalize features (4 points): apply min-max scaling to appropriate numerical measurements and compare results. Do not normalize trip identifiers.
  5. Validate and reflect (4 points): verify the cleaned data and discuss results and limitations.

Checkpoint hints

Consult only what you need. These examples use a separate toy table; write your own bike-trip code.

1. Inspect a table 
toy = pd.DataFrame({"item_id": [1, 2, 3], "label": [" A ", "b", None],
                    "mass_g": [10, -2, None]})
toy.shape
toy.dtypes
toy["mass_g"].describe()

A column's stored type does not determine its role. Decide whether arithmetic on it has meaning.

2. Find issues 
toy.isna().sum()
toy.duplicated().sum()
toy["label"].value_counts(dropna=False)
toy.loc[toy["mass_g"] <= 0]

The duplicate count gives extra copies, not all members of duplicate groups. Use the dataset rules to distinguish invalid values from unusual but valid values.

3. Clean without changing the original 
revised = toy.copy().drop_duplicates()
revised["label"] = revised["label"].str.strip().str.lower()
revised["label"] = revised["label"].fillna("unknown")
revised["mass_g"] = revised["mass_g"].mask(revised["mass_g"] <= 0)
# Choose ONE policy: drop missing measurements or fill them.
# Tools: dropna(subset=[...]) or fillna(a_justified_value)

Compute any replacement statistic after removing duplicate records and invalid measurements. A median is one possible replacement; explain your choice.

4. Scale a measurement 
values = pd.Series([5.0, 10.0, 15.0])
low, high = values.min(), values.max()
scaled = 0.0 if high == low else (values - low) / (high - low)

Apply the formula separately to each suitable measurement. A value halfway through the observed range need not be the median.

5. Check your results 
import math
assert revised["item_id"].is_unique
assert not revised.duplicated().any()
revised.isna().sum()
revised["label"].isin(["a", "b", "unknown"])
# For a numerical Series s:
# s.map(math.isfinite).all()
# (s > 0).all()
# s.between(-1e-10, 1 + 1e-10).all()  # scaled values only

Use .all() to combine row-by-row checks. Check category membership after standardizing strings. Compare min() and max() with the expected scaled endpoints, allowing rounding tolerance. Use pd.testing.assert_frame_equal(raw, pd.read_csv("week01-campus-bike-trips.csv")) to check raw preservation.
