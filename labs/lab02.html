Troubleshooting

A variable is undefined after restarting
A restart clears runtime variables. Run cells from the loading cell onward; old displayed output does not mean its variable still exists.
The hosted CSV will not load
Check your connection and rerun the loading cell. If GitHub is unavailable, download the CSV above, upload it through Colab's Files panel, and change the read_csv argument to the uploaded filename. Ask the instructor if the dataset link remains unavailable.
A cell runs but shows nothing
Assignments and comments do not automatically display a table. Use display(...) for results. The provided table-comparison assertion finishes silently if it passes.
An optional missing label causes a failed check
Missing rider types are allowed. Check known rider labels against allowed categories and required measurements separately.
The exported CSV has an extra column
Export again with index=False, then reload. The DataFrame index is not one of the required columns.
