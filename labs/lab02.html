Removing rows with missing measurements

Sometimes an analysis needs a value in each of several columns. dropna() can remove rows that lack those required values. The subset argument tells pandas which columns to check.

This example uses a separate table of package measurements:

packages = pd.DataFrame({
    "package": ["A", "B", "C", "D"],
    "mass_g": [100, None, 300, 400],
    "length_cm": [10, 20, None, 40],
    "label": ["small", "medium", "large", None]
})

complete = packages.dropna(subset=["mass_g", "length_cm"])
complete

Result: packages A and D remain. B is missing mass; C is missing length. D stays because its missing label is not one of the required measurements.

  • By default, how="any" removes a row if either selected column is missing. Both measurements must be present to keep the row.
  • how="all" would remove a row only when both selected columns are missing; that is a different rule.
  • Without subset, pandas checks every column, which could remove rows just because an optional label is missing.
  • Assign the returned table to a variable. This example leaves packages unchanged.

dropna() detects missing values, not invalid measurements such as negative lengths. Mark invalid values as missing first, then remove rows according to the required-column rule. Removing incomplete rows also changes which observations are represented; consider how that could affect your conclusions.

For future datasets, a constant column has zero range and standard deviation, so these formulas need an explicit zero-denominator policy. This lab’s cleaned measurements are nonconstant.

Troubleshooting

CSV not found after restarting
Upload the original CSV through the Files panel, check its exact filename, and rerun from the acquisition cell.
A missing rider label causes validation to fail
The policy permits missing rider labels. Check known labels against the allowed categories and check required measurements separately.
Z-score standard deviation looks wrong
Use ddof=0 for both the transformation and its summary. pandas otherwise defaults to the sample standard deviation.
The reloaded CSV has an extra column
Check whether you exported the DataFrame index. Export again with index=False, then reload the new file.
