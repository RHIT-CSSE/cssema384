Optional Colab guide

Colab reference: import libraries and install packages

Import makes an installed library available in a Python code cell. Run imports again after restarting the runtime.

import pandas as pd
import math

# pd is a short alias for pandas.
pd.read_csv("week01-campus-bike-trips.csv")

Install adds a package to the current runtime. Colab already includes pandas; this lab does not require installing anything. In a separate practice notebook, use %pip in a code cell if you need an additional package:

%pip install package_name

Replace package_name with the actual package name from its documentation, then import it in another cell. Installation names and import names sometimes differ. Follow any restart instruction shown after installation, then rerun your imports. Packages installed in a temporary runtime may need to be installed again in a new runtime.

Reference only: do not add installation commands to your Lab 01 submission. Its required libraries are already available. A ModuleNotFoundError can indicate a misspelled import or a missing package; check the package documentation first.

When something goes wrong

NameError: a variable is missing
Run the cell that defines the missing variable, then rerun the current cell. Restarting clears variables, even when old outputs remain visible.
CSV file not found
Upload the CSV in the Files panel and check that its name matches the code exactly. A GitHub notebook does not bring its CSV into Colab. Upload it again after a runtime reset.
My output did not change
Editing a cell does not execute it. Run the edited cell and then any cells that use its values, in order.
