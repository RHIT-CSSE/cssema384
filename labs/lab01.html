Lab 01: Google Colab Foundations

Practice

Learn notebook-based analysis with a small synthetic campus bike-trip dataset.

Learning objectives

  • Create, save, and run code and Markdown cells.
  • Use Python expressions and import pandas.
  • Load a CSV and inspect a DataFrame with head(), shape, columns, and info().

Preparation

Read DSD 3.1.1–3.1.2 (notebooks and data formats); review DSD 1.1–1.3 (data science and data types). No Python installation is required.

Activities and checkpoints

  1. Save your own notebook copy, connect, and compare code with Markdown.
  2. Try Python expressions and add your own cells.
  3. Load and inspect the bike-trip CSV, then record observations.
  4. Save, download, reopen, and rerun your work.

Complete the notebook’s Try It Yourself activities. Detailed exercises are in the notebook.

Independent Coding Practice: AI Assistance Off

In Colab, open Tools > Settings > AI Assistance. Where available, turn off Show AI-powered inline completions and turn on Hide generative AI features, then save. Labels vary by account; ask the instructor to verify settings if needed. Do not use AI chat, Generate, or Help me code.

Complete exercises without code or answers generated by ChatGPT, Gemini, Copilot, or similar assistants. Standard non-generative editor completion is allowed. Use readings, documentation, provided examples, and instructor help. See the Colab FAQ.

Open the notebook

Open in Colab · Download notebook · Download dataset (CSV)

  1. Open in Colab, sign in, and select File > Save a copy in Drive.
  2. Click Connect to start a standard Python runtime.
  3. Download the CSV above, then upload it with the Colab Files panel (folder icon > Upload). Opening a GitHub notebook does not upload its CSV.

Uploaded files are temporary; upload the CSV again after a runtime reset. Keep the original dataset unchanged.

Quick reference and hints

Use these when stuck; they are not extra tasks.

  • Cells: use + Code or + Text. Shift+Enter runs the selected cell. Double-click a text cell to edit Markdown.
  • Variables: minutes = 12 stores a value; minutes * 3 uses it. Rerun edited cells to update their outputs.
  • NameError: run the cell that defines the missing variable. Restarting clears variables, even when old outputs remain visible.
  • CSV not found: upload the file in the Files panel and check that its name matches the code exactly. A GitHub notebook does not bring its CSV into Colab.
