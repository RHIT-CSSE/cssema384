2. Data sources

Choosing a data source

Who or what produced the observations?

Who is included in the data? Who might be missing?

A downloadable CSV is a snapshot; an API provides programmatic access; logging records events as a system runs. The access method does not guarantee that the observations are complete or appropriate. Check permission and terms before collecting or reusing data.

For our labs, the CSV is supplied and intentionally synthetic. It is useful for practicing analysis, but it is not evidence of real campus travel. In a real study, you would also need to understand how trips were recorded and whether some stations or riders were excluded.

Reading: DSD §3.2, Collecting Data.

3. Observations and features

One row represents one trip

Columns describe the trip. A row records one observation.

First two records of the supplied synthetic bike-trip CSV
trip_idstationrider_typeduration_mindistance_km
1001librarystudent122.4
1002sciencestaff183.6

Before calculating a summary, identify what each row represents.

Here the unit of observation is a trip, not a rider or a station. Multiple trips can start at the same station. Without a rider identifier, this table cannot tell us how many distinct people traveled.

The lab notebook's data dictionary defines positive durations in minutes and positive distances in kilometers. Blank fields mean unknown. Category case and surrounding spaces do not change meaning. Knowing those rules helps distinguish a suspicious value from a valid observation.

4. Feature roles

Identifiers, categories, and measurements

Identifier

trip_id

Which trip?

Arithmetic has no useful interpretation.

Category

station

Which group?

Compare labels and group counts.

Measurement

duration_min

How much?

Compare quantities with units.

Choose summaries based on what a column means, not just its stored type.

pandas may store an identifier as an integer, but averaging trip IDs does not summarize trip behavior. A station label encoded as 1, 2, or 3 remains a category. A numeric column with missing values may be loaded as floating point; that storage choice does not change its conceptual role.

Apply the same reasoning to the remaining columns: rider_type identifies a category and distance_km records a measurement. These distinctions matter when selecting summaries and, later, deciding which features can be scaled.

5. Python example

Inspecting a CSV with pandas

Load the CSV, then check its rows, columns, and data types.

import pandas as pd

raw = pd.read_csv("week01-campus-bike-trips.csv")
raw.head(2)
raw.shape
raw.info()
head(2) → previewshape → dimensionsinfo() → types & non-missing counts

Use the full table to check for missing or invalid values.

In Colab, upload the CSV through the Files panel before running this code. The notebook does not bring its dataset along automatically. The preview matches the two records above; raw.shape returns a tuple in the order (rows, columns). raw.info() prints a summary; it does not return a new DataFrame.

Run raw.columns to check column names. Compare each non-missing count with the total row count. A smaller count signals missing entries, but a fully populated column can still contain invalid values or inconsistent labels.

These are inspection examples, not cleaning steps. Keep the original CSV unchanged and preserve raw when you later create a cleaned copy. Code is displayed here; run it in the Lab 01 notebook.

6. Discussion

Discuss: what can we conclude?

A student previews two rows and says:

“All trips have positive durations, and campus riders prefer the library station.”
  1. Which part needs a whole-table check?
  2. Which part needs a different source of evidence?
  3. What would you inspect next, and why?

Discussion notes

A two-row preview cannot establish that every duration is positive. You need a check across the full column using the dataset's validity rules. Counting stations in this synthetic exercise also cannot establish real preferences: the data were created for practice, and a trip count alone does not explain a rider's motivation.

In Lab 02, collect evidence about missing values, duplicates, labels, and measurements before cleaning. Explain the scope of every claim: “in this file” is different from “among campus riders.” Passing technical checks does not establish representative sampling.
